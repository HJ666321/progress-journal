# i_cru_ur[159:0] 字段映射表

## 概述

`i_cru_ur` 是 User Register 模块的控制寄存器输入信号，共 160 位。

## 字段布局

从低位到高位排列顺序：
```
写端口0 -> 写端口1 -> 写端口2 -> 写端口3 -> 读端口0 -> 读端口1 -> 读端口2 -> 读端口3
```

每个端口的内部格式（从低到高）：
- **写端口 (28位)**: `{we, wbank[2:0], waddr[7:0], wbe[15:0]}`
- **读端口 (12位)**: `{re, rbank[2:0], raddr[7:0]}`
