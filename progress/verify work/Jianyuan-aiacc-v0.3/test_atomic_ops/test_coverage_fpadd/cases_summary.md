# FPADD 覆盖测试用例说明

每个用例验证一种 **源精度 × 目的精度 × 状态更新 × 操作类型** 的组合。
- **FP16**：单拍处理 8 个元素 (S[0-7]→D[0-7])。
- **FP32**：单拍处理 4 个元素 (S[0-3]→D[0-3])。

| 用例 | 源精度 | 目的精度 | 状态更新 | 操作类型 | 功能说明 |
|------|--------|----------|----------|----------|----------|
| fpadd_case0001 | FP16 | FP16 | 否 | 加法 | FP16 加法 (A+B)，8 个 lane (不更新状态寄存器) |
| fpadd_case0004 | FP32 | FP32 | 否 | 加法 | FP32 加法 (A+B)，4 个 lane (不更新状态寄存器) |
| fpadd_case0005 | FP16 | FP16 | 是 | 加法 | FP16 加法 (A+B)，8 个 lane (且更新状态寄存器) |
| fpadd_case0008 | FP32 | FP32 | 是 | 加法 | FP32 加法 (A+B)，4 个 lane (且更新状态寄存器) |
| fpadd_case0009 | FP16 | FP16 | 否 | 减法 | FP16 减法 (A-B)，8 个 lane (不更新状态寄存器) |
| fpadd_case0012 | FP32 | FP32 | 否 | 减法 | FP32 减法 (A-B)，4 个 lane (不更新状态寄存器) |
| fpadd_case0013 | FP16 | FP16 | 是 | 减法 | FP16 减法 (A-B)，8 个 lane (且更新状态寄存器) |
| fpadd_case0016 | FP32 | FP32 | 是 | 减法 | FP32 减法 (A-B)，4 个 lane (且更新状态寄存器) |

## 字段含义

- **源精度**: FP16 (8 lane) / FP32 (4 lane)。
- **目的精度**: FP16 / FP32 (通常与源一致)。
- **状态更新**: 是否更新状态寄存器 (GT, EQ, LS 标志)。
- **操作类型**: 加法或减法。
