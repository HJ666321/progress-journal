### `CAMConf` - CAM 键值配置

**作用**:
`CAMConf` 用于向 CAM 表中写入一个具体的条目。这即是当数据包经过处理后，提取出的密钥将要与之进行比较的**目标键值**。

**代码分析**:
1.  **文件**: `emit-pkt.cpp`
2.  **函数**: `printCAMConf`
3.  **关键代码**:
    ```cpp
    static void printCAMConf(struct LookupCAMConf &cam_conf, std::ostream &os, int stage, 
    							int entry_ind, uint32_t vid) {
        os << "CAMConf ";
        printStageInd(os, MODULE_LOOKUP, stage, entry_ind, 0, 0);
        // print vid, 12 bit
        // ...
        // print data (op_6B_1, op_6B_2, op_4B_1, op_4B_2, op_2B_1, op_2B_2)
        // ...
        os << "0"; // 附加的条件位
        os << "000\n"; // 填充位，凑齐 208 比特
    }
    ```

**配置解析**:

**第一行: 地址与元数据 (`000100100000000000000000`)**

| 比特位置 | 长度 (比特) | 二进制值 | 十进制值 | 作用和说明 (代码依据) |
| :--- | :--- | :--- | :--- | :--- |
| 1-8 | 8 | `00010010`| 18 | **模块与阶段ID**。高5位(`00010`)是阶段2，低3位(`010`)是查找模块(2)。 |
| 9-16 | 8 | `00000000`| 0 | **保留/模式位**。 |
| 17-24 | 8 | `00000000`| 0 | **表项索引**。这是该条目在CAM表中的地址，这里是第**0**项。 |

**第二行: 键值数据 (`0000...00010000...`)**
这一行定义了要写入CAM的208位数据。

| 比特位置 (从左到右) | 长度 (比特) | 二进制值               | 作用和说明                                     |
| :---------- | :------ | :----------------- | :---------------------------------------- |
| 1-12        | 12      | `000000000001`     | **VID**。这个CAM条目关联的VID是**1**。              |
| 13-60       | 48      | `00...0`           | **`op_6B_1`**: 第一个6字节密钥部分的值。              |
| 61-108      | 48      | `00...0`           | **`op_6B_2`**: 第二个6字节密钥部分的值。              |
| 109-140     | 32      | `00...0`           | **`op_4B_1`**: 第一个4字节密钥部分的值。              |
| 141-172     | 32      | `00...0`           | **`op_4B_2`**: 第二个4字节密钥部分的值。              |
| 173-188     | 16      | `0000000000000000` | **`op_2B_1`**: 第一个2字节密钥部分的值。              |
| 189-204     | 16      | `0000000000000001` | **`op_2B_2`**: 第二个2字节密钥部分的值。这里被设为了 **1**。 |
| 205         | 1       | `0`                | **附加条件位**。                                |
| 206-208     | 3       | `000`              | **填充位**。                                  |

**小结**:
这条 `CAMConf` 配置的含义是：“在**查找模块(2)**的**阶段2**，向CAM表的**第0个位置**写入一个条目。这个条目关联的**VID为1**，其键值中，与 `op_2B_2` 对应的部分为 `1`，其余部分全部为 `0`。”
