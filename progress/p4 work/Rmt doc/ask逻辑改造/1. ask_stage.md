## 主要输入与输出

- **输入**
  - `axis_clk` : 时钟
  - `aresetn` : 复位
  - `phv_in` : 数据包头信息（PHV）
  - `phv_in_valid` : PHV有效信号
  - `vlan_in` : VLAN信息
  - `vlan_valid_in` : VLAN有效信号
  - `stage_ready_in` : 下游阶段就绪信号
  - `vlan_out_ready` : VLAN输出就绪信号
  - **AXIS控制信号组**（打包说明）：
    - `c_s_axis_tdata`, `c_s_axis_tuser`, `c_s_axis_tkeep`, `c_s_axis_tvalid`, `c_s_axis_tlast`

- **输出**
  - `phv_out` : 处理后的PHV
  - `phv_out_valid` : 处理后的PHV有效信号
  - `stage_ready_out` : 本阶段就绪信号
  - `vlan_ready_out` : VLAN就绪信号
  - `vlan_out` : VLAN输出
  - `vlan_valid_out` : VLAN输出有效信号
  - **AXIS控制信号组**（打包说明）：
    - `c_m_axis_tdata`, `c_m_axis_tuser`, `c_m_axis_tkeep`, `c_m_axis_tvalid`, `c_m_axis_tlast`

## 子模块数据通路（datapath）简述

### 1. ask_extract

- **输入**：PHV、有效信号、上游ready信号
- **输出**：提取后的PHV、bitmap、ptype、ready信号
- **功能**：从输入PHV中提取关键字段（如key、value、bitmap、ptype），为后续聚合做准备。

### 2. aggregator_top

- **输入**：提取后的PHV、4组key/value、base_addr、valid_bitmap、is_even_seq、index、is_empty、is_update、is_aggr_pkt、valid_in、ready_in
- **输出**：聚合后的PHV、valid_out、ready_out
- **功能**：根据输入的key/value等信息进行聚合操作，输出处理后的PHV。

---

## AXIS信号组说明

- 所有AXIS相关信号（`c_s_axis_*` 和 `c_m_axis_*`）在本模块中仅做寄存器透传，不参与数据处理，仅用于控制通路的同步和数据流转。

---

**总结**：  
ask_stage模块的主要数据流为：  
PHV输入 → ask_extract提取关键信息 → aggregator_top聚合处理 → PHV输出。  
VLAN和AXIS信号则直接透传或简单同步。
